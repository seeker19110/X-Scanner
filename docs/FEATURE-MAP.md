## Luồng chính (đối chiếu Definition of Complete)

- **LC-1 Chụp → chỉnh → xuất PDF** (FT-02, FT-08, FT-10): widget test qua `ReviewScreen` với nguồn ảnh/chia sẻ giả — `review_screen_test` "captured image appears as a page", "crop button opens the editor and saves its result", "exporting as PDF shares one X-Scanner.pdf (AC-6) (F-029)"; `quad_editor_screen_test` "a valid drag moves only that corner". Test đi liền một mạch: `review_screen_test` "LC-1: capture, move a corner, save and export as PDF in one flow (F-053)". AC-9 đã được root nghiệm thu18Oct theoủyquyền qua agent-run WindowsWHPX emulator, bằng chứng `docs/ops/evidence/p1-android-uat-2026-10-18/ac9.json`; không camera vật lý.
- **LC-2 Đóng app → mở lại → còn trang và chỉnh sửa** (FT-01): `document_store_test` "a new store on the same folder restores the document" + các ca (F-001); `session_controller_test` "restore loads the saved session", "(F-001) restore failing with an I/O error, then capture, keeps the …".
- **LC-3 Nhập ảnh hỏng/huỷ → không mất trang cũ** (FT-02, FT-03, FT-12): `review_screen_test` "cancelled capture adds no page (AC-7)", "undecodable image shows a message and keeps pages (AC-7)"; `session_controller_test` "cancelled capture adds no page and no notice (AC-7)".
