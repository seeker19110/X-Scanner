# docs/goals — Checkpoint goal nhiều PR

> Mục tiêu kéo dài qua nhiều PR/phiên dùng một file `docs/goals/<id>.md`
> (mẫu: `docs/framework/templates/GOAL.template.md`). Mỗi vòng lặp ghi lại checkpoint:
> slice đã chọn, kết quả, khoảng cách còn lại so với Goal DoD, trạng thái BLOCKED/WAITING nếu có.
> Luật gốc: `docs/framework/standard-delivery.md` §4 (AI Goal Loop).
